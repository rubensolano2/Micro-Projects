# Micro-Projects

Índice de ideas para proyectos de análisis de datos y machine learning en Python.

**Estado del repositorio:** actualmente contiene este documento. No hay notebooks, scripts, datasets ni resultados versionados; por eso los temas siguientes se presentan como propuestas.

## Temas propuestos

| Tema | Pregunta de análisis | Enfoque previsto |
| --- | --- | --- |
| Destinos de senderismo | ¿Qué destinos reciben menos atención? | Exploración y visualización |
| Precios de viviendas | ¿Qué características explican el precio? | Regresión y evaluación del error |
| Productividad y conexión social | ¿Qué asociaciones aparecen en los datos? | Análisis exploratorio; sin inferir causalidad |
| Reseñas de productos electrónicos | ¿Qué temas y valoraciones se repiten? | Procesamiento de texto |
| Ofertas de empleo | ¿Qué señales ayudan a detectar ofertas fraudulentas? | Clasificación y análisis de falsos positivos |
| Ventas de libros | ¿Cómo evolucionan las ventas? | Series temporales |
| Catálogo de Netflix | ¿Cómo se distribuye el catálogo? | Limpieza, agregaciones y visualización |
| Jugadores de FIFA 22 | ¿Cómo se comparan perfiles de jugadores? | Exploración de atributos |
| Ventas de supermercados | ¿Qué patrones de compra aparecen? | KPIs y análisis de ventas |
| Cadenas de comida rápida | ¿Cómo se comparan las principales cadenas? | Análisis descriptivo |

## Criterios para incorporar un proyecto

Un proyecto se añadirá al índice con un enlace real cuando incluya:

1. Una pregunta concreta, la fuente de datos y sus condiciones de uso.
2. Un notebook o script reproducible y las dependencias necesarias.
3. Limpieza de datos, comprobaciones de calidad y explicación del método.
4. Resultados calculados, visualizaciones y limitaciones.
